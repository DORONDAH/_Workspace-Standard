# Project Truth

This memory records the canonical mission, principles, and constraints for the Workspace Standard repository.

**Mission:** Transform this repo into a governed, autonomous AI workspace architecture.
**Principles:** Multi-Agent ≠ Multi-Authority; Evidence-Based; Deterministic.
**Invariants:** Separation of reasoning and authority; no silent failure fallback; machine-validated completion.

**Why:** To establish a source of truth for all subsequent implementation, governance, and agent-interaction design in the repository.
**How to apply:** All new tasks and agent contracts must be validated against these invariants.
