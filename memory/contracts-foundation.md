# Contracts Foundation

This memory marks the implementation of Agent and Task contracts, enabling machine-readable governance.

**Components:**
- `commander-contract.yaml`: Explicit role, authority, and constraints for the Workspace Commander.
- `template-task.yaml`: Standardized structure for all executable tasks.

**Why:** To ensure every agent is constrained by an explicit contract and every task is unambiguous and verifiable.
**How to apply:** All new agents must reference their definition, and all tasks must be instantiated from the task template.
